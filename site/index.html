VIII

Questions

Is Cloister really free?

Yes. It is open source under the MIT licence. There is no paid tier, no ads and no account.

Can Cloister read my messages?

No. Each service runs as its normal website in its own private profile on your computer. Cloister only sees what a notification would show, uses it to display that notification, and never stores it on disk or sends it anywhere. Find in page searches the page's text inside the page itself.

How is it lighter than other all-in-one apps?

Most of them ship a full copy of Chromium. Cloister uses the browser engine your system already has (WebView2 on Windows, WebKit on macOS and Linux), so the Windows download is a few megabytes, and services you rarely check can be paused or put to sleep.

Will it update itself?

Yes. Cloister checks for new versions on start and every few hours, and shows an Update button when one is ready. Updates are signed, so only genuine releases install, and nothing changes until you click. Your services and sign ins stay as they are.

Something does not work. Where do I report it?

Please open an issue on GitHub with your system and what you saw. Pull requests are welcome too.
