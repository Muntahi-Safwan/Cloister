Cloister keeps WhatsApp, Discord, Gmail, Messenger and the rest in a single lightweight app. One click blurs every chat when someone walks past. A focus session holds your notifications until you are ready for them.

For Windows, macOS and Linux.

Works with

WhatsApp · Messenger · Discord · Gmail · Outlook · Telegram · Slack · Microsoft Teams · Facebook · LinkedIn · Proton Mail · and any site you add yourself

Built for the hours you spend in chat

Veil

Blur every conversation with one shortcut. Hover a single chat to read it while the rest stay hidden, and notifications drop their message text until you lift it.

Focus sessions

Start a 25 minute session and Cloister quietly holds every notification. When it ends you get one calm summary of what you missed, with your important people let through.

App lock

Lock Cloister behind Windows Hello on start, after you have been away, or whenever you like. Every page is hidden, not just covered.

Light on memory

Built with Rust and the browser engine already on your computer, so there is no bundled Chromium. Pages you have not opened in a while go to sleep, and settings show what each one uses.

Notifications that lead somewhere

Native toasts that open the right service when clicked, unread badges in the sidebar and taskbar, quiet hours, and a history of the last fifty, kept in memory only.

Private by design

No account, no telemetry and no server of its own. Every service keeps its own separate sign in, and one click signs you out and wipes its data.

Install

Pick your system. Cloister updates are published on GitHub Releases.

Windows

Windows 10 and 11, 64 bit
Download installer (.exe)

MSI package for managed installs

Windows says it "protected your PC"

Cloister is not code-signed yet, so SmartScreen does not recognise it. Click More info, then Run anyway. You only need to do this once.

macOS

macOS 11 or later, Apple Silicon and Intel
Download for Mac (.dmg)

One universal app for every Mac

macOS says it "cannot be opened"

Cloister is not notarised by Apple yet. Drag it to Applications, try to open it once, then go to System Settings › Privacy & Security and click Open Anyway. If macOS says the app is damaged, run this in Terminal and open it again: 

xattr -cr /Applications/Cloister.app

Linux

64 bit, X11 or Wayland
Download AppImage

Or the .deb for Debian and Ubuntu, .rpm for Fedora and openSUSE

How do I run the AppImage?

Make it executable once, then double-click it or run it from a terminal:

chmod +x Cloister_*.AppImage
./Cloister_*.AppImage

Feature notes: app lock uses Windows Hello, so it is Windows only for now. On macOS, each service keeps a separate sign in on macOS 14 and later. Everything else works the same everywhere.

Questions

Is Cloister really free?

Yes. It is open source under the MIT licence. There is no paid tier, no ads and no account.

Can Cloister read my messages?

No. Each service runs as its normal website inside its own private browser profile on your computer. Cloister only sees what a notification would show, uses it to display a toast, and never stores it on disk or sends it anywhere.

How is it lighter than other all-in-one apps?

Most of them ship a full copy of Chromium. Cloister is written in Rust with Tauri and uses the browser engine your system already has (WebView2 on Windows, WebKit on macOS and Linux), so the download is a few megabytes and idle pages can be put to sleep.

Will it update itself?

Not yet. New versions appear on the GitHub releases page; install the new one over the old one and your services and sign ins stay as they are.

Something does not work. Where do I report it?

Please open an issue on GitHub with your system and what you saw. Pull requests are welcome too.
